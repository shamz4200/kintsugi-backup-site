# Kintsugi Backup website

Public informational pages for the personal Kintsugi Backup OAuth application. **Never commit secrets, tokens, backup archives or Kintsugi's private source code to this repository.**

## Publish with GitHub Pages

1. Upload `index.html`, `privacy.html`, and `style.css` to the **root** of the `main` branch of `shamz4200/kintsugi-backup-site`.
2. Go to repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. Wait for GitHub to show the live site. Expected addresses (verify before use):
   - Home: https://shamz4200.github.io/kintsugi-backup-site/
   - Privacy: https://shamz4200.github.io/kintsugi-backup-site/privacy.html
5. Visit both URLs to confirm they load before entering them in Google Cloud OAuth Branding.

Note: Publishing the OAuth app can introduce Google verification requirements. Check the Google Cloud console and do not assume publication or verification is automatic.
