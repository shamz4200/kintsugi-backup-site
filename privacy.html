KINTSUGI · PRIVACY

Privacy Policy

Last updated: 17 October 2026

About this application

Kintsugi Backup is a personal utility that uses Rclone to access a Google Drive account with the account owner's authorization. It is not a publicly offered backup service.

Google account data

With permission, the utility accesses Google Drive files within the scope granted by the user (currently the Google Drive drive.file scope). This is used to create, list, retrieve and manage backup-related files that the application is authorized to access.

Backup contents

Backup archives are intended to be encrypted locally using Restic before transfer to Google Drive. The backup operator controls which local files are included. The website itself does not receive backup contents, passwords, OAuth tokens or Google Drive files.

Storage and sharing

Rclone stores OAuth credentials locally on the operator's device. Encrypted backup archives are stored in the operator's Google Drive account. The application operator does not sell personal information or intentionally share backup contents with third parties. Google's processing of data stored on Drive is governed by Google's applicable terms and policies.

Retention and deletion

The operator manages backup retention and can remove archives from Google Drive. The account owner can revoke OAuth access through their Google Account settings. Revoking access does not automatically delete existing backup files.

Security

Local encryption is intended to protect backup contents before upload. No backup system guarantees absolute security; protection depends on the operator safeguarding encryption passwords, devices and account access.

Contact

For questions about this private utility, contact the application operator using the support email shown on the Google OAuth consent screen.
